## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Build environment → runtime | NEXT_PUBLIC_API_URL is inlined at build time; a missing var crashes the build (correct behavior) rather than silently routing to a dead endpoint |
| Supabase query → component | Typed Database generic ensures query results are type-checked at compile time, preventing shape-mismatch runtime errors |
