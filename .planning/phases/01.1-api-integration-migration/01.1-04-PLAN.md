| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01.1-13 | Denial of Service | batch upload file count and size | medium | transfer | Bounds are backend-enforced (`upload_batch` validates content types and runs `_cleanup_batch` as a compensating transaction on partial failure; per-request rate limiting is active server-side). | T-01.1-14 | Tampering | filenames rendered in `share-file-list.tsx` and `batch-upload-result.tsx` | low | mitigate | Filenames are rendered as React text children, which escape by default.
