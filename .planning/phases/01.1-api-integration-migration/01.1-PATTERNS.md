### `app/api/profile/route.ts` (new, Route Handler — profile write)

**Analog:** `app/api/shares/[slug]/access-cookie/route.ts` (lines 1-17) — the established precedent for a frontend-only Route Handler using project conventions (Next.js `NextRequest`/`NextResponse`, no external service call).

**Imports + shape pattern to copy:**
```typescript
import { NextRequest, NextResponse } from "next/server";
import { cookies } from "next/headers";
import { createAdminClient } from "@/utils/supabase/server";
import { getSessionUser } from "@/lib/firebase/server";

export async function PUT(request: NextRequest) {
  const cookieStore = await cookies();
  const user = await getSessionUser(cookieStore);
  if (!user) {
    return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
  }

  const body = await request.json().catch(() => null);
  const displayName = typeof body?.display_name === "string" ? body.display_name.trim().slice(0, 100) : null;
  if (!displayName) {
    return NextResponse.json({ error: "display_name is required" }, { status: 400 });
  }

  const admin = createAdminClient();
  const { error } = await admin
    .from("user_profiles")
    .update({ display_name: displayName })
    .eq("user_id", user.uid);

  if (error) {
    return NextResponse.json({ error: "Failed to update profile" }, { status: 500 });
  }
  return NextResponse.json({ ok: true });
}
```

Note per CONTEXT.md D-02: this writes to the frontend's own Supabase `user_profiles` table — a different table from `dropitx-api`'s Postgres `user_profiles` read by `GET /api/auth/session`. Do not import `authFetch`/`getApiUrl` here — this route never calls the FastAPI backend.

```typescript
const uploadBatch = useCallback(
  async (files: File[]) => {
    setState("uploading");
    setErrorMessage("");
    try {
      const formData = new FormData();
      files.forEach((f) => formData.append("files", f));

      const response = await authFetch("/api/upload/batch", {
        method: "POST",
        body: formData,
      });
      const data = await response.json();
      if (!response.ok) {
        setState("error");
        setErrorMessage(data.error || "Upload failed.");
        return;
      }
      setState("success");
      onBatchUploadSuccess?.(data as BatchUploadResult); // new prop, mirrors onMultiUploadSuccess
    } catch {
      setState("error");
      setErrorMessage("Network error. Please try again.");
    }
  },
  [onBatchUploadSuccess],
);
```

```typescript
"use client";
import { useCallback, useEffect, useState } from "react";
import { getApiUrl } from "@/lib/api-client";

export default function ExplorePage() {

      setError("Couldn't load Explore. Retry.");
```

## Shared Patterns

### Authenticated fetch (`authFetch`/`getApiUrl`)
**Source:** `lib/api-client.ts:9-49`
**Apply to:** Every client component calling `dropitx-api` while authenticated — Stars toggle, Encryption dialog, Upload batch, Domains/File Requests row actions.
```typescript
import { authFetch, getApiUrl } from "@/lib/api-client";
// authFetch injects Authorization: Bearer <Firebase ID token>, retries once on 401
// getApiUrl is for public/unauthenticated fetches (Explore, Public Profile SSR read)
```
Never write a bespoke `fetch` wrapper for a new endpoint group — this is the single required entry point (per RESEARCH.md's "Don't Hand-Roll" table).
